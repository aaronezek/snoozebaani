# Snoozebaani

Should you nap right now? Snoozebaani takes a few quick inputs and tells you whether a nap will help, how long to sleep, and when to set your alarm.

## What it looks at

- Hours you slept vs. how much you need (sleep debt)
- When you woke up and when you're going to bed
- The time of day (your natural afternoon dip)
- How sleepy and how stressed you feel
- Caffeine you've had today and how much is still active
- How much free time you have

The answer updates as you tap. Your last inputs are saved in your own browser only; nothing is sent anywhere.

## Running it

It's a single file with no build step. Open `index.html` in a browser, or host it anywhere that serves static files (GitHub Pages, Netlify, Vercel).

## Disclaimer

General guidance, not medical advice. If you're regularly exhausted despite enough sleep, talk to a doctor.
